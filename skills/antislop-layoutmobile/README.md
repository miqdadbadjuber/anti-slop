# antislop-layoutmobile

Mobile layout rules for generated interfaces. When your AI tool builds a layout, this skill checks that it still holds up on a small screen: breakpoints, grids, overflow, tap targets, and navigation. Part of the antislop system.

## What it is not

Not a responsive framework, and it will not write your CSS. It checks that a layout holds up on a phone and fixes what breaks. The layout structure stays yours.

## Where the rules live

Your AI agent loads this together with the core rules in `antislop.md`. The full detail is in `SKILL.md` in this folder.
